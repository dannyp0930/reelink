# 롯데시네마 굿즈 source 사전 검증

- 조사일: 2026-09-03
- 대상: 롯데시네마 공식 Web의 굿즈 이벤트 목록과 지점별 재고 상태
- 결론: 이벤트 탐색은 가능하지만 지점별 availability를 확인할 수 없어 collector 후보로 채택하지 않음

## 판단

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| Event discovery | 가능 | 공식 [굿즈 이벤트 목록](https://www.lottecinema.co.kr/NLCHS/Event/DetailList?code=20)에서 진행 중인 이벤트 제공 |
| 참여 극장 확인 | 가능 | 이벤트 상세 본문에 진행 극장과 증정품, 증정 기간 표시 |
| 지점별 availability | 확인 불가 | 상세는 선착순 증정과 지점별 소진 시점 차이만 안내하며 현재 재고 상태는 제공하지 않음 |
| 로그인 | 불필요 | 비회원 브라우저에서 목록과 상세 확인 가능 |
| 일반 HTTP 접근 | 가능 | 목록, 상세, `robots.txt`가 일반 HTTP client에서 `200 OK` 응답 |
| API 안정성 | 낮음 | 브라우저 내부 endpoint이며 공개 API 문서와 변경 보장 없음 |
| 제품 사용 권한 | 확인 필요 | 이용약관이 영리 목적 활동과 게시 자료의 가공·판매·배포를 제한 |

현재 공개 화면만으로는 Reelink의 핵심 요구인 지점별 availability를 만들 수 없다. 롯데시네마 collector는 구현하지 않고, 정식 data feed나 사용 허가를 확보한 뒤 다시 판단한다.

## 화면에서 확인한 정보

굿즈 이벤트 목록은 별도 카테고리로 제공된다. 각 항목에서 제목, 시작일, 종료일, 굿즈 분류를 확인할 수 있다.

2026-09-03에 확인한 `<캐리어를 끄는 소녀> 1주차 현장 증정 이벤트` 상세는 다음 정보를 담고 있었다.

- 진행 기간: 2026-09-02 ~ 2026-09-08
- 진행 극장: 광복, 센텀시티, 신도림
- 증정품: 메인 포스터 `(Tennis) A3`
- 증정 방식: 관람 당일 선착순 증정

상세에는 “조기소진 될 수 있습니다. (소진 시점 지점별 상이)”라는 안내만 있다. CGV처럼 극장별 상태를 보여주는 표나 재고 단계는 찾지 못했다.

이벤트 주요 내용은 이미지 한 장의 대체 텍스트에도 함께 들어간다. 화면 구조와 이미지 작성 방식이 바뀌면 참여 극장이나 증정품 파싱이 깨질 가능성이 높다.

## Network 관찰

브라우저에서 목록과 상세를 열 때 다음 read endpoint가 호출되는 것을 확인했다.

```text
https://www.lottecinema.co.kr/LCWS/Event/EventData.aspx
```

배포된 JavaScript bundle에서는 요청 본문에 다음 method와 값을 사용하는 것을 확인했다.

```text
GetEventLists
GetInfomationDeliveryEventDetail
EventClassificationCode: "20"
```

`GetEventLists` 요청에는 검색어, 영화관, page number와 size, 정렬 조건, 회원 번호가 포함된다. 비회원 회원 번호는 `"0"`이다. 상세는 `EventID`로 조회한다.

이 endpoint는 공개 문서가 없는 내부 구현이다. URL과 method name이 노출돼 있어도 collector 계약이나 재사용 허가로 간주하지 않는다. 본 검증에서는 브라우저가 실제로 보낸 요청만 관찰했고, endpoint를 반복 호출하거나 세션을 복제하지 않았다.

## robots.txt와 정책

[robots.txt](https://www.lottecinema.co.kr/robots.txt)는 일반 user-agent에 빈 `Disallow`를 둔다. 크롤링 금지 경로가 명시되지 않았다는 뜻일 뿐, 제품에서 데이터를 사용하거나 재배포해도 된다는 허가는 아니다.

[롯데시네마 이용약관](https://www.lottecinema.co.kr/NLCHS/Etc/MemberClause)에서 확인한 제한은 다음과 같다.

- 제14조 제6항은 사전승낙 없는 영업 및 기타 영리 목적 활동을 제한한다.
- 제16조 제2항은 서비스에서 얻은 정보의 가공·판매 등 게시 자료의 상업적 사용을 제한한다.
- 제17조 제3항은 사전 승낙 없는 정보의 복제, 송신, 출판, 배포, 방송과 영리 목적 이용 또는 제3자 이용을 제한한다.

이 문서는 법률 자문이 아니다. 실제 서비스에 롯데시네마 데이터를 넣기 전에는 롯데컬처웍스의 서면 허가와 필요하면 별도 법률 검토가 필요하다.

## 권장안

1. 롯데컬처웍스에 굿즈 이벤트와 지점별 상태의 사용 범위, 갱신 주기, 표시 조건을 문의한다.
2. 지점별 재고 또는 소진 상태를 제공하는 정식 data feed가 있는지 확인한다.
3. 허가와 availability feed가 없으면 롯데시네마 collector를 만들지 않는다.
4. 공식 이벤트 링크를 관리자가 직접 등록하는 방식은 출처와 사용 범위를 확인한 뒤 별도로 검토한다.
5. 다음 후보인 메가박스를 같은 기준으로 조사한다.

## 재검증 조건

- 롯데시네마가 지점별 재고나 소진 현황 화면을 제공할 때
- 공식 API나 제휴 feed를 제공할 때
- 이용약관이나 `robots.txt`가 바뀔 때
- 롯데컬처웍스에서 데이터 사용 범위를 답변할 때
