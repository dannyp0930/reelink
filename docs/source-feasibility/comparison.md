## 결론

현재 공개 화면만으로 자동 수집을 시작할 source는 없다. 메가박스가 지점별 굿즈 상태를 제공해 기술 후보로는 가장 앞서지만, `robots.txt`, 약관, 내부 endpoint라는 제약 때문에 collector 구현은 하지 않는다. 개인 프로젝트 MVP는 공식 링크와 수동 관측값으로 진행한다.

Phase 0 종료 조건은 다음과 같다.

1. 이벤트와 지점별 상태의 필드 정의, 확인 시각, 출처 표기 조건을 문서로 확정한다.
2. 자동 수집 없이 관리자 등록·사용자 제보 기반 수동 흐름을 MVP 범위로 확정한다.
3. 이후 자동화는 source별 정책과 제공 방식이 확인될 때 별도 판단한다.

## 구현으로 넘어갈 때

사용 가능한 source가 확인되면 PostgreSQL + Prisma 스키마에서 다음을 분리한다.

- `GoodsCampaign`: 영화별 캠페인과 기간
- `GoodsItem`: 포스터·티켓·카드 등 품목
- `CinemaGoodsStatus`: 극장별 현재 관측 상태
- `GoodsObservation`: 확인 시각·출처·관측자·원문 링크
- `GoodsCandidate`: 자동 또는 수동 입력 후 관리자 승인 대기

source가 하나도 승인되지 않으면 위 구조는 수동 입력을 먼저 지원하고, collector adapter는 추가하지 않는다.
