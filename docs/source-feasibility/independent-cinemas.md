# 독립영화관 굿즈 source 사전 검증

- 조사일: 2026-09-03
- 대상: 인디스페이스와 아트나인 공개 채널을 대표 표본으로 확인
- 결론: 극장별 공지와 이벤트 발견에는 유용하지만, 재고 자동 수집 source로 쓰기에는 갱신성과 사용 권한 확인이 부족함

인디스페이스 공식 사이트는 상영시간표, 작품별 상영일정, 정기상영·기획전, 개봉작 이벤트 메뉴를 제공한다. 다만 경품 안내 페이지는 “실시간 업데이트되지 않습니다”라고 명시하고, 증정품도 소진 시 종료된다고 안내한다. 따라서 이벤트 존재를 확인하는 데는 쓸 수 있지만 현재 재고를 나타내는 source로 쓰면 안 된다.

## 공통 판단

독립영화관은 대형 체인보다 극장별 운영 방식과 게시 채널이 제각각이다. 굿즈 공지는 홈페이지보다 Instagram, X, 블로그, 뉴스레터에 먼저 올라올 수 있고, 지점별 재고는 현장 문의로만 확인되는 경우가 많다.

- Event discovery: 공식 홈페이지·블로그·SNS에서 가능
- 지점별 availability: 공개 구조화 데이터 확인 안 됨
- API/feed: 대표 표본에서 확인 안 됨
- 자동 수집 권한: 각 운영자 확인 필요
- 안전한 MVP 방식: 관리자 링크 등록, 수동 관측값, 원문 링크 보존

## 권장안

1. 독립영화관은 첫 자동 collector 대상에서 제외한다.
2. 영화관별로 공식 Website, RSS, 뉴스레터, SNS 중 운영자가 허용하는 채널을 문의한다.
3. 초기에는 극장명, 영화명, 굿즈, 증정 조건, 확인 시각, 원문 URL만 관리자 입력으로 저장한다.
4. 운영자가 data feed를 제공하는 극장만 별도 adapter 후보로 승격한다.
5. 사용자가 제보한 현장 관측값은 공식 정보와 분리하고, 만료 시각을 둔다.
