# 메가박스 굿즈 source 사전 검증

- 조사일: 2026-09-03
- 대상: 메가박스 공식 Web의 굿즈 이벤트와 극장별 소진 현황
- 결론: 기술상 세 후보 중 가장 적합하지만 `robots.txt`와 이용약관 때문에 허가 전 자동 수집은 보류

## 판단

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| Event discovery | 가능 | 공식 [진행중 이벤트](https://www.megabox.co.kr/event)에서 메가Pick·영화 등 이벤트 목록 제공 |
| 지점별 availability | 가능 | 이벤트 상세의 `굿즈 소진현황 보기`에서 지역·극장별 상태 제공 |
| 상태 종류 | 확인 | `보유`, `소량보유`, `준비중` 상태를 화면에서 확인 |
| 로그인 | 불필요 | 비회원 브라우저에서 이벤트와 소진 현황 확인 가능 |
| 일반 HTTP 접근 | 가능 | 이벤트·상세 페이지가 일반 HTTP client에서 `200 OK` 응답 |
| API 안정성 | 낮음 | 공개 문서 없는 내부 endpoint이며 HTML 응답 구조에 의존 |
| robots.txt | 차단 신호 | 일반 user-agent에 `Disallow: /` |
| 제품 사용 권한 | 확인 필요 | 약관이 사전 승낙 없는 영리 이용, 복제·유통·제3자 제공을 제한 |

메가박스는 현재 확인한 극장 중 유일하게 지점별 굿즈 상태를 공식 화면에서 제공한다. 다만 화면에도 “선착순 증정으로 현장상황과 다를 수 있습니다”라고 표시된다. Reelink에서 사용하더라도 공식 재고가 아닌 관측값으로 표시해야 한다. 허가와 정식 feed 없이는 collector를 구현하지 않는다.

## 화면에서 확인한 정보

2026-09-03에 [메가박스 오리지널 티켓 No.185 `<싱 어게인>`](https://www.megabox.co.kr/event/detail?eventNo=21167) 상세를 확인했다.

- 이벤트 기간: 2026-09-03 ~ 2026-09-16
- `굿즈 소진현황 보기` 버튼 제공
- 서울·경기 등 지역별 극장 그룹 제공
- 극장 상태: `보유`, `준비중` 확인

이전 이벤트인 메가박스 오리지널 티켓 No.184 `<인 더 그레이>`에서는 `소량보유`도 확인했다. 상태는 실시간 현장 재고와 다를 수 있으므로 `LIKELY_AVAILABLE`, `LOW_OR_DEPLETING`, `PENDING` 같은 관측 상태로만 정규화한다. `SOLD_OUT`은 이번 표본에서 확인하지 않았으므로 임의로 매핑하지 않는다.

## Network 관찰

이벤트 목록은 브라우저에서 다음 내부 endpoint를 호출한다.

```text
POST /on/oh/ohe/Event/eventMngDiv.do
```

JSON 요청에 이벤트 상태, 분류, 검색어, 페이지 정보를 넣고 HTML 목록을 받는다. 이벤트 상세의 소진 현황 버튼은 다음 endpoint를 호출한다.

```text
POST /on/oh/ohe/Event/selectGoodsStockPrco.do
```

요청 파라미터는 상세 HTML에서 확인한 `eventNo`와 `goodsNo`다. 응답 HTML에 지역, 극장명, 상태 문구가 들어가며, 브라우저는 이를 `굿즈 소진현황` 레이어로 표시한다.

두 endpoint 모두 공개 API 문서가 없는 내부 구현이다. 본 검증에서는 공식 페이지를 열어 브라우저가 실제로 보낸 요청과 렌더링 결과만 관찰했다. 반복 호출, 로그인 세션 복제, 우회, 대량 수집은 하지 않았다.

## robots.txt와 정책

[robots.txt](https://www.megabox.co.kr/robots.txt)는 다음과 같이 모든 경로를 차단한다.

```text
User-agent: *
Disallow: /
```

이는 자동 수집을 진행하지 말아야 할 명확한 신호다. [메가박스 이용약관](https://www.megabox.co.kr/support/terms)에서도 다음 제한을 확인했다.

- 제7조 제2항 제9호: 사전 승낙 없는 정보의 복제·유통·상업적 이용 금지
- 제11조 제4항: 사전승낙 없는 영업활동 금지
- 제11조 제6항 제2호: 사전승낙 없는 정보의 복제·출판·방송·제3자 제공 금지
- 제11조 제6항 제7호: 명시적 허가 없는 프로그램의 Web/App 서버 접근 금지
- 제19조 제3항: 사전 승낙 없는 정보의 영리 목적 이용 또는 제3자 이용 금지

이 문서는 법률 자문이 아니다. 실제 서비스에 메가박스 데이터를 넣기 전에는 메가박스중앙의 서면 허가와 필요하면 별도 법률 검토가 필요하다.

## 권장안

1. 메가박스중앙에 굿즈 이벤트·극장별 상태의 제품 사용 허가를 문의한다.
2. 허가 요청 시 정식 API 또는 data feed, 호출 빈도, cache 정책, 상태 정의, 출처 표기 조건을 함께 확인한다.
3. 허가 전에는 `eventMngDiv.do`와 `selectGoodsStockPrco.do`를 직접 호출하는 collector를 만들지 않는다.
4. 허가를 받으면 메가박스를 첫 번째 goods source 후보로 삼고, 상태를 관측값으로 저장하며 관리자 승인 후 공개한다.
5. 허가가 없으면 공식 링크와 사용자가 직접 입력한 관측값만 저장하는 수동 흐름을 별도로 검토한다.

## 재검증 조건

- 메가박스가 서면 사용 허가나 정식 feed를 제공할 때
- `robots.txt` 또는 이용약관이 변경될 때
- 굿즈 소진 현황의 상태 종류나 응답 구조가 변경될 때
- 화면 상태와 현장 재고의 차이를 보정할 공식 기준이 제공될 때
