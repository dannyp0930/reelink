# Instagram 굿즈 source 사전 검증

- 조사일: 2026-09-03
- 대상: 영화관·배급사·독립영화관의 공개 Instagram 게시물
- 결론: 보조적인 이벤트 발견 채널로만 사용하고, Instagram 자체를 자동 수집 source로 채택하지 않음

## 판단

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| Event discovery | 제한적 가능 | 공개 계정 게시물에서 이벤트 공지와 굿즈 정보를 확인할 수 있음 |
| 지점별 availability | 대체로 불가 | 게시물은 선착순·소진 안내를 담을 수 있지만 현재 지점별 재고를 보장하지 않음 |
| 공식 API | 범위 확인 필요 | Meta가 제공하는 API는 계정 유형과 권한에 따라 접근 범위가 다르며 일반 공개 게시물 검색용 API로 간주하지 않음 |
| 로그인 | 경우에 따라 필요 | 공개 Web은 로그인·지역·세션 상태에 따라 표시가 달라질 수 있음 |
| 자동 수집 | 보류 | Meta는 자동 데이터 수집을 scraping으로 설명하고 무단 수집에 rate limit·차단 등 대응을 적용함 |
| 콘텐츠 재사용 | 허가 필요 | 이미지·영상·문구는 계정 소유자 또는 제3자 권리 대상일 수 있음 |

Meta는 [데이터 scraping 안내](https://www.facebook.com/help/463983701520800)에서 자동 수집을 설명하고, 무단 수집에 요청 제한과 차단을 적용한다고 밝힌다. [저작권 안내](https://www.facebook.com/help/354736791367645/)도 공개된 인터넷 콘텐츠라는 이유만으로 재게시 권리가 생기지 않는다고 안내한다.

## Reelink에서 허용할 범위

Instagram은 원문 콘텐츠를 복제하는 source가 아니라 이벤트 발견용 링크로 다룬다.

- 관리자가 공식 계정과 게시물 URL을 등록한다.
- 제목, 게시일, 영화명, 극장명, 이벤트 기간처럼 사실 필드만 기록한다.
- 이미지·영상은 저장하거나 재배포하지 않고 원문 링크로 연결한다.
- 재고 상태는 게시물 게시 시점의 안내로 표시하고, 현재 공식 재고로 표현하지 않는다.
- 계정 로그인, private API, 세션·cookie 복제, 우회·대량 수집은 사용하지 않는다.

## 권장안

1. Phase 0에서는 대표 계정의 공개 게시물 10~20건을 표본으로 삼아 이벤트 정보 필드가 얼마나 일정한지 확인한다.
2. 자동 수집은 Meta 공식 API와 계정 소유자의 명시적 권한이 확인될 때만 별도 검토한다.
3. 허가 전 MVP는 관리자 링크 등록과 사용자 제보를 우선한다.
4. 게시물 삭제·수정에 대비해 원문 URL, 확인 시각, 마지막 확인자를 함께 남긴다.

## 재검증 조건

- Meta API의 현재 권한 범위와 Reelink 사용 목적이 일치할 때
- 계정 운영자 또는 권리자로부터 서면 사용 허가를 받을 때
- 게시물에서 구조화된 feed 또는 공식 RSS를 제공할 때
