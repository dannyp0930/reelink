# 씨네Q 굿즈 source 사전 검증

- 조사일: 2026-09-03
- 대상: 씨네Q 공식 Web의 영화관 이벤트와 굿즈 증정 안내
- 결론: 이벤트 탐색은 가능하지만 지점별 실시간 availability를 확인할 수 없어 자동 수집 후보로 채택하지 않음

## 판단

| 항목 | 결과 | 근거 |
| --- | --- | --- |
| Event discovery | 가능 | 공식 [이벤트 목록](https://www.cineq.co.kr/Event/List)에 영화관이벤트와 영화이벤트 메뉴가 있음 |
| 굿즈 정보 | 제한적 가능 | 공식 [굿즈 증정 방식 안내](https://www.cineq.co.kr/Customer/NoticeInfo/358)와 개별 이벤트 페이지에서 증정 조건을 확인할 수 있음 |
| 지점별 availability | 확인 불가 | 확인한 안내는 증정 시간과 소진 시 종료를 설명하지만 지점별 현재 재고를 제공하지 않음 |
| 로그인 | 불필요 | 비회원 브라우저에서 이벤트 목록과 공지 확인 가능 |
| 비브라우저 접근 | 미검증 | 이번 조사는 화면과 공개 문서 확인에 한정하며 내부 endpoint 호출은 하지 않음 |
| API 안정성 | 낮음 | 공개 API 문서나 변경 보장이 확인되지 않음 |
| 제품 사용 권한 | 확인 필요 | [이용약관](https://mobile.cineq.co.kr/terms.html)은 사전 승낙 없는 정보의 복제·유통·상업적 이용을 제한함 |

씨네Q는 영화관 이벤트와 굿즈 안내를 공개하지만, Reelink의 핵심 요구인 극장별 현재 상태는 화면에서 확인되지 않았다. 자동 collector는 구현하지 않고, 정식 data feed 또는 서면 허가를 확보한 뒤 다시 판단한다.

## 화면에서 확인한 정보

이벤트 목록에는 `전체이벤트`, `영화관이벤트`, `영화이벤트` 구분이 있다. 씨네Q 공지는 굿즈가 관람 전후 특정 시간에 증정되며 소진될 수 있고, 배급사 요청이나 극장 사정에 따라 증정 방식이 바뀔 수 있다고 안내한다.

따라서 공개 페이지에서 얻을 수 있는 값은 다음 수준이다.

- 영화와 이벤트 제목
- 증정품 종류와 증정 조건
- 대상 극장 또는 상영 조건이 이벤트 본문에 있을 때의 참여 범위
- 공지 등록일과 이벤트 기간

실제 잔여 수량이나 지점별 소진 단계는 확인할 수 없다. Reelink에 입력하더라도 `OFFICIAL_STOCK`이 아니라 이벤트 안내 또는 관리자 확인값으로 분리해야 한다.

## 정책과 권장안

씨네Q 약관은 사전 승낙 없이 서비스에서 얻은 정보를 복제·유통하거나 상업적으로 이용하는 행위를 제한한다. 공개 화면이라는 이유만으로 제품 수집·재배포 권한이 생기지 않는다.

1. 씨네Q에 이벤트 정보와 굿즈 조건의 제품 사용 범위, 갱신 주기, 출처 표기 조건을 문의한다.
2. 지점별 재고나 소진 상태를 제공하는 정식 API 또는 data feed가 있는지 확인한다.
3. 허가 전에는 내부 endpoint 추정, 로그인 scraping, 반복 호출을 하지 않는다.
4. 허가가 없으면 공식 링크와 관리자가 직접 입력한 관측값만 사용하는 수동 흐름을 검토한다.

## 재검증 조건

- 씨네Q가 지점별 소진 상태나 정식 feed를 제공할 때
- 이용약관 또는 이벤트 화면 구조가 바뀔 때
- 씨네Q가 제품 사용 범위를 서면으로 답변할 때
